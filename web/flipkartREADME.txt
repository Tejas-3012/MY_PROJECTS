# FLIPKART HOMEPAGE CLONE

## Project Title

Flipkart Homepage Clone using HTML & CSS

---

## Project Description

This project is a front-end clone of the Flipkart homepage developed using HTML5 and CSS3. It recreates the basic user interface of Flipkart, including the navigation header, search bar, product categories, promotional banner, product sections, and footer.

The project is designed for learning modern web development concepts such as Flexbox, CSS Grid, positioning, hover effects, responsive layouts, and UI cloning.

No JavaScript has been used in this project.

Contains common styling used throughout the website.
