# YOUTUBE HOMEPAGE CLONE

## Project Title

YouTube Homepage Clone using HTML & CSS

---

## Project Description

This project is a front-end clone of the YouTube homepage developed using HTML and CSS. It recreates the overall layout and appearance of YouTube, including the navigation header, sidebar, search bar, and video grid.

The project is intended for learning modern web design techniques such as Flexbox, CSS Grid, responsive layouts, image positioning, and hover effects.

---

## Technologies Used

* HTML5
* CSS3
* Google Fonts (Roboto)

1. Download or clone the project.

2. Keep all folders in the same directory.

3. Open:

youtube.html

in your preferred web browser.

No server or additional software is required.
